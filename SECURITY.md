# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Use GitHub's private reporting instead: **Security tab → Report a vulnerability** on this repository. You will get an answer within 7 days.

## If you find a leaked secret in this repository

All secrets in tests are generated at runtime and the example files only contain obvious fake placeholders. If you believe a real credential was committed, report it privately as described above.

## Supported versions

Only the latest release receives security fixes.
